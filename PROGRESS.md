Every request (incl. each redirect hop and robots.txt) passes url_safety, robots.txt (cached per site, follows up to 5 safe redirects, cautious on 401/403/429/5xx/unreachable, Crawl-delay honored up to 60 s), a per-host rate limit (>= 1 s), and our own DNS resolution where every address must be public; the request then goes to that exact IP with the real name as Host and TLS SNI (no second lookup to rebind). GET only, no cookies kept, proxy env ignored, timeouts, 5 MB cap, 5 redirects. Login walls (401, password field, login paths incl. redirects to them) are reported and not crawled; dead ends are skipped automatically but "Check now" retries. HTML via trafilatura with an lxml visible-text fallback for short pages; PDF and text/plain (declared charset) supported. Conditional requests (ETag / Last-Modified). `page_snapshots` (text + whitespace-insensitive hash + changed flag, newest 5 kept); source check status fields; `POST /sources/{id}/check`, `/paste` (FR-D4), `GET /sources/{id}/snapshot`. Migrations now render `UTCDateTime` as plain `sa.DateTime` (regression test). **Tested:** 284 pytest (57 new: fake web, fake DNS, fake clock); deliberate breaks (no IP pinning, redirects not re-checked, robots ignored, no rate limit) each failed tests. Live checks: example.com over http/https through the pinned-IP path; self-signed and expired certificates refused; a name pointed at another site's IP fails safely (server-side handshake refusal; client hostname checking relies on Python's default `check_hostname=True`, confirmed by config, not by a live failure). Found and fixed: short pages had no text; misleading "robots disallowed" messages for DNS blocks and TLS failures; robots.txt redirects not followed.
